# Calculadora-ensamblador

Calculadora modular en lenguaje ensamblador x86-64 para Linux.

## Pasos para ejecutar

1. Abrir una terminal en la carpeta `CALCULADORA-ENSAMBLADOR`
2. Ejecutar el script de compilación:

```bash
./scripts/compile.sh
```

3. Ejecutar la calculadora:

```bash
./calculadora
```
